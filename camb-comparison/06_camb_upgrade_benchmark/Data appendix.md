# Data appendix — CAMB2 upgrade benchmark

[Short report](Short%20report.md) · [Detailed report](Report.md) · [Figure index](Figure%20index.md)

The reports focus on the usual settings and the recombination
comparison at `AccuracyBoost = 1`. This appendix also preserves the
earlier precision tests and CLASS checks for reference. Those tests
do not set the working precision or the reported speedup.
The `low_cdm` run is retained here as a separate diagnostic from the
October pilot design; it is not part of the 52 cases shown in the reports.

CAMB2 means version 2.0.5 throughout. A comparison with an older build
uses that older build as the denominator: a positive signed difference
means that CAMB2 predicted more power. Differences and RMS values are
in **percent**; wavenumbers are in **Mpc⁻¹** and times are in **seconds**.
The full machine-readable spectra, individual timing samples and resolved
solver settings remain in the local research folder.
